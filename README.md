# Nutrition Tracker

A solo built full-stack nutrition tracking application that allows users to search for foods, track nutritional intake, and save food logs to their personal accounts.

## Tech Stack

**Frontend**

- React
- TypeScript
- HTML
- CSS

**Backend**

- Node.js
- Express.js
- PostgreSQL
- REST APIs
- bcrypt for password hashing
- Express Session for authentication sessions

**External APIs**

- Open Food Facts API for food search

## Features

- **Food Search:** Search for foods and retrieve nutritional information.
- **Nutrition Tracking:** Log foods with weights, calories, carbohydrates, protein, and fat.
- **Meal Organization:** Organize food logs by meal, including breakfast, lunch, dinner, and snacks.
- **User Authentication:** Register and log in with email and password.
- **Session Management:** Maintain login sessions and support logging out.
- **User-Specific Food Logs:** Associate saved food entries with individual user accounts.
- **Persistent Storage:** Store user accounts and food logs in PostgreSQL.
